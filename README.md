# Lint Rules

Tooling and rules for Oxlint.

## Packages

- `oxlint-vitest-rule-tester`: Utility to test rules in vitest.
- `@benjavicente/lint-angular`: Angular injection context rules.

## Development

From the repo root, use Vite+ (`vp`) for installs and monorepo scripts:

```sh
vp i
vp run pr
```

Run commands with `vp run {command}`.
